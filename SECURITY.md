# Security policy

ESP32 Tailnet is experimental networking software and has not received a
security audit. Do not publish suspected vulnerabilities in a public issue.
Contact the repository owner privately with a minimal reproduction, affected
version or commit, and impact assessment.

Never attach auth keys, device identities, packet captures containing private
traffic, Wi-Fi credentials, or production firmware images to a report. Rotate
any credential that may have been exposed during investigation.

Only the latest tagged release and the current `main` branch are intended to
receive security fixes.
